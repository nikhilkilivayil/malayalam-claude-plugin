# Manglish → Malayalam and romanization

"Manglish" is Malayalam typed with Latin letters. It has no fixed standard: the
same writer may spell one word several ways. Convert by *reading* the Manglish as
spoken Malayalam and writing the correct dictionary spelling, not by mapping letters
one-to-one. The tables below give the usual conventions (close to the Mozhi
keyboard scheme used by most Malayalam input tools).

## Vowels

| Manglish | Malayalam (independent / sign) | Example |
|---|---|---|
| a | അ / (inherent) | kalam → കളം |
| aa, A | ആ / ാ | aana → ആന |
| i | ഇ / ി | ini → ഇനി |
| ee, ii, I | ഈ / ീ | veedu → വീട് |
| u | ഉ / ു | udayam → ഉദയം |
| oo, uu, U | ഊ / ൂ | oonu → ഊണ് |
| e | എ / െ | ente → എന്റെ |
| E, ae (long e) | ഏ / േ | vEnam / venam → വേണം |
| ai | ഐ / ൈ | kai → കൈ |
| o | ഒ / ൊ | oru → ഒരു |
| O, oa (long o) | ഓ / ോ | Onam → ഓണം |
| au, ou | ഔ / ൗ | kauthukam → കൗതുകം |
| am (final) | ം | maram → മരം |
| ah (final) | ഃ | rare |
| ru, R (vocalic) | ഋ / ൃ | krishi → കൃഷി |

Writers rarely mark vowel length. Decide long vs short from the word:
"kalam" is കളം (ground) or കാലം (time) depending on context; "veedu" is വീട്.

## Consonants

| Manglish | Malayalam | Notes |
|---|---|---|
| k, kk | ക, ക്ക | kh → ഖ, g → ഗ, gh → ഘ; ng → ങ്ങ inside words (ingane → ഇങ്ങനെ), but n before k/g is often anusvara (mangalam → മംഗളം, sankadam → സങ്കടം) |
| ch, cch | ച, ച്ച | chh → ഛ, j → ജ, jh → ഝ, nj → ഞ (njan → ഞാൻ, njangal → ഞങ്ങൾ) |
| T, t (retroflex) | ട | Th → ഠ, D → ഡ, Dh → ഢ, N → ണ |
| th (dental) | ത | thh → ഥ, d → ദ, dh → ധ, n → ന |
| p, pp | പ, പ്പ | ph/f → ഫ, b → ബ, bh → ഭ, m → മ |
| y | യ | r → ര, l → ല, v/w → വ |
| S, sh (palatal) | ശ | sh (retroflex) → ഷ, s → സ, h → ഹ |
| L | ള | zh → ഴ (Kozhikode → കോഴിക്കോട്), R / rr → റ (ara → അറ) |
| tt | റ്റ | (in loanwords: catt → ക്യാറ്റ്) or ട്ട (kotta → കോട്ട); decide by word |
| nn | ന്ന / ണ്ണ | enna → എന്ന, kannu → കണ്ണ് |
| nt / nth | ന്റ / ന്ത | ente → എന്റെ, santhosham → സന്തോഷം |
| nd | ണ്ട / ന്ദ | undu → ഉണ്ട്, nandi → നന്ദി |
| mb | മ്പ | kambi → കമ്പി |
| ksh | ക്ഷ | raksha → രക്ഷ |
| jn / gn | ജ്ഞ | jnanam → ജ്ഞാനം |

Manglish "th", "t", "d", "n", "l", "r", "s" are ambiguous between dental/retroflex
and between ല/ള, ര/റ, ശ/ഷ/സ. Resolve with the real word: "pani" is പണി (work)
or പനി (fever) — choose by context; "kalu" is കാല് (leg); "mala" is മല (hill) or
മാല (necklace).

## Word-final sounds

- A final consonant with no vowel is usually a **chillu** when it is ണ, ന, ര, ല, ള:
  avan → അവൻ, aval → അവൾ, avar → അവർ, kaal → കാൽ, kan → കൺ, nal → നാൾ.
  But a dative -n (to him) is ന്: avanu → അവന്.
- Final "u" after other consonants is the **samvruthokaram**: athu / ath → അത്,
  ithu → ഇത്, innu → ഇന്ന്, aanu → ആണ്. (illa → ഇല്ല ends in a full vowel: no virama.)
- Final "am" → ം: maram → മരം, snEham → സ്നേഹം.
- Final "e" is usually െ: ente → എന്റെ, ninte → നിന്റെ, nale → നാളെ.

## Mixed English

Manglish messages often contain English words: "meeting kazhinju vilikkam".
When converting, keep English words either in Latin script ("meeting കഴിഞ്ഞ്
വിളിക്കാം") or as Malayalam-script loanwords (മീറ്റിംഗ് കഴിഞ്ഞ് വിളിക്കാം) — ask or
follow the user's preference; the Latin-script form is normal in chat, the
Malayalam-script form in publications.

## Romanization for scholarly or official use

- **ISO 15919** (academic): മലയാളം → malayāḷaṁ, കേരളം → kēraḷaṁ, ഴ → ḻ, ള → ḷ,
  ണ → ṇ, ട → ṭ, റ → ṟ, ഞ → ñ, ങ → ṅ, ശ → ś, ഷ → ṣ.
- **Common/official spellings** are conventional, not systematic: Thiruvananthapuram,
  Kozhikode, Thrissur, Alappuzha, Pathanamthitta, Malappuram. Use the official
  spelling for names of places, people and institutions rather than a transliteration
  scheme.
- Personal names follow the bearer's own spelling (Nikhil, Anjali, Sreekumar, Gopalakrishnan).
