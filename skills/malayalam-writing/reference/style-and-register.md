# Style, register and Kerala conventions

## Registers

| Register | Where | Traits |
|---|---|---|
| Standard written (മാനക മലയാളം) | news, documents, textbooks, UI, official letters | full verb forms (ചെയ്യുന്നു, ചെയ്തു), joined sandhi, no dialect words |
| Colloquial (സംസാരഭാഷ) | chat, dialogue, ads, social media | contracted forms (ചെയ്യുകയാണ് → ചെയ്യുവാ, എന്താണ് → എന്താ, വേണ്ടേ), particles (അല്ലേ, ആണല്ലോ, ട്ടോ), English code-mixing |
| Literary / elevated | speeches, literature, religious text | Sanskrit-derived vocabulary, long compounds, honorific plurals |

Regional colour: Thiruvananthapuram (ചെയ്യുവോ, അണ്ണാ), Kochi/central (ചെയ്യുവാ,
ചേട്ടാ), Malabar (ചെയ്യ്വോ, ഇക്കാ/ഇത്താ, കുട്ട്യേ). Only use dialect when the user
asks for a specific voice; the default is region-neutral standard Malayalam.

## Politeness and address

| Pronoun | Use |
|---|---|
| താങ്കൾ | formal, respectful singular (letters, customer support, strangers of status) |
| നിങ്ങൾ | neutral/polite singular and plural; the safe default for UI and general text |
| നീ | intimate, or to children/juniors; rude to strangers |
| അദ്ദേഹം / അവർ | respectful "he" / "they" (also used for one respected person) |
| അവൻ / അവൾ | plain "he" / "she"; can sound dismissive for adults in formal text |

Kin terms are used as polite address to non-relatives: ചേട്ടാ / ചേച്ചി (older
brother/sister), അണ്ണാ, ഇക്കാ / ഇത്താ (Muslim communities in Malabar), മാഷേ /
ടീച്ചറേ (teachers), സാർ / മാഡം (formal).

Request forms, from most formal to casual:

1. … ചെയ്യേണ്ടതാണ്. (official notices: "is to be done")
2. ദയവായി … ചെയ്യുക. (written polite imperative)
3. … ചെയ്യണം. (plain "should", neutral)
4. … ചെയ്യൂ. / … ചെയ്യാമോ? (spoken polite)
5. … ചെയ്യ്. (bare imperative, intimate)

## Grammar notes

- SOV; postpositions (-ൽ in, -ലേക്ക് to, -ൽനിന്ന് from, -ഓട് with/to a person,
  -ക്ക് dative, -ന്റെ/-ഉടെ genitive, -കൊണ്ട് instrumental).
- No grammatical gender or number agreement on verbs.
- Tense: past (-ഇ / -ഉ: പോയി, കണ്ടു), present (-ഉന്നു: പോകുന്നു), future (-ഉം:
  പോകും). Progressive: പോയിക്കൊണ്ടിരിക്കുന്നു. Perfect: പോയിട്ടുണ്ട്.
- Negation: ഇല്ല (not/there isn't), അല്ല (is not, copular), വേണ്ട (don't want / don't),
  അരുത് (must not). ഞാൻ വരില്ല (I won't come); ഇത് ശരിയല്ല (this is not right).
- Copula: ആണ് / ആകുന്നു (formal) / ആയിരിക്കും (will be); often dropped in
  headlines.
- Questions: clitic -ഓ for yes/no; interrogatives ആര് (who), എന്ത് (what), എവിടെ
  (where), എപ്പോൾ (when), എങ്ങനെ (how), എന്തുകൊണ്ട് (why), ഏത് (which).
- Reported speech uses എന്ന്: വരാമെന്ന് അവർ പറഞ്ഞു.
- Plural: -കൾ (പുസ്തകങ്ങൾ, കുട്ടികൾ, വീടുകൾ); -മാർ for people and kin (ഡോക്ടർമാർ,
  അമ്മമാർ); some human nouns take -ർ (അധ്യാപകർ, കർഷകർ, തൊഴിലാളികൾ → -കൾ).
  കുട്ടികൾ, never കുട്ടിമാർ.

## Numbers

| Digits | Words |
|---|---|
| 1–10 | ഒന്ന്, രണ്ട്, മൂന്ന്, നാല്, അഞ്ച്, ആറ്, ഏഴ്, എട്ട്, ഒൻപത്, പത്ത് |
| 100, 1,000 | നൂറ്, ആയിരം |
| 1,00,000 | ഒരു ലക്ഷം |
| 1,00,00,000 | ഒരു കോടി |

- Indian digit grouping: 12,34,567 (twelve lakh thirty-four thousand …).
- Ordinals: ഒന്നാം, രണ്ടാം, മൂന്നാം … (ഒന്നാം സ്ഥാനം); "the nth one" = -ാമത്തെ
  (മൂന്നാമത്തെ ആൾ).
- Currency: ₹500 or 500 രൂപ; paise = പൈസ.
- Percent: 25% or 25 ശതമാനം.

## Dates and time

- Gregorian months: ജനുവരി, ഫെബ്രുവരി, മാർച്ച്, ഏപ്രിൽ, മേയ്, ജൂൺ, ജൂലൈ,
  ഓഗസ്റ്റ്, സെപ്റ്റംബർ, ഒക്ടോബർ, നവംബർ, ഡിസംബർ.
- Weekdays: ഞായറാഴ്ച, തിങ്കളാഴ്ച, ചൊവ്വാഴ്ച, ബുധനാഴ്ച, വ്യാഴാഴ്ച, വെള്ളിയാഴ്ച,
  ശനിയാഴ്ച.
- Formats: 2026 സെപ്റ്റംബർ 7 (news style) · 7 സെപ്റ്റംബർ 2026 · 07-09-2026 (dd-mm-yyyy).
  Point in time: സെപ്റ്റംബർ 7-ന് (on the 7th). Time: രാവിലെ 9 മണിക്ക്, വൈകിട്ട് 5.30-ന്.
- Malayalam calendar (കൊല്ലവർഷം, ME): year ≈ Gregorian − 825; months ചിങ്ങം,
  കന്നി, തുലാം, വൃശ്ചികം, ധനു, മകരം, കുംഭം, മീനം, മേടം, ഇടവം, മിഥുനം, കർക്കടകം.
  Festivals: ഓണം (ചിങ്ങം, Aug–Sep), വിഷു (മേടം 1, mid-April).

## Formatting Malayalam text

- Use a Unicode Malayalam font stack in documents/web: Noto Sans Malayalam,
  Manjari, Meera, Rachana, Chilanka (all free); never rely on legacy ASCII fonts
  such as "ML-TTKarthika" (that text is not real Unicode Malayalam).
- Line-height ≥ 1.6 for body text: conjuncts and vowel signs need vertical room.
- Do not letter-space Malayalam (it breaks conjunct shaping).
- Keep numerals and English acronyms in Latin script inline (ഐഎസ്ആർഒ or ISRO
  are both seen; be consistent).
